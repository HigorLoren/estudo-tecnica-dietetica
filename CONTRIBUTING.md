# Como contribuir

Sugestões para melhorar a experiência de estudo e correções de conteúdo são bem-vindas.

## Preparar uma alteração

1. Faça uma cópia do projeto e instale as dependências com `npm ci`.
2. Execute `npm run dev` para abrir o site localmente.
3. Mantenha a alteração focada e siga as convenções dos arquivos existentes.
4. Execute `npm test` e `npm run build` antes de compartilhar o resultado.
5. Descreva o que mudou e como verificou o resultado. Para alterações visuais, inclua capturas de tela quando possível.

## Conteúdo e progresso

Confira fontes, unidades, fórmulas, respostas aceitas e explicações ao alterar o conteúdo. Não invente dados ou referências. Preserve a compatibilidade com o progresso salvo no navegador sempre que possível.

Antes de adicionar imagens ou outros materiais externos, verifique sua origem e condições de redistribuição. Não inclua credenciais, dados pessoais ou arquivos de ambiente no repositório.
